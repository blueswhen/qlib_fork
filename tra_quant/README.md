# tra_quant

This directory keeps the reproducible TRA best-baseline package.

## From-Zero Full Retrain

Use this entry when the goal is to rebuild the current best stage1 + stage2
baseline without relying on archived intermediate artifacts:

```bash
cd /home/blueswhen/DL/qlib_fork/tra_quant
./retrain_best_baseline_from_zero.sh \
  --run-id best_baseline_from_zero_YYYYMMDD_N \
  --gpu-slots 0,1 \
  --stage2-num-shards 8
```

The script always creates a new directory under `runs/` and refuses to start if
that run id already exists. Do not resume an interrupted run directory for a
formal reproduction; start again with a new run id.

The only external data dependency is raw training data under:

```text
/home/blueswhen/DL/qlib_fork/training_data
```

The script copies only source files into the fresh run tree, then checks that no
`.pkl`, `.csv`, `.json`, `.txt`, or `.log` intermediate artifacts were copied.
Stage1 cache paths written into the generated wrapper summaries must all point
inside the current run directory. Stage2 CV search is run with
`--force-recompute` and must use the stage1 summary/repro JSON generated by the
same run.

For the two non-seed42 TRA stage1 seeds, the script retrains the validation and
test base caches from scratch and writes a base-run summary. It intentionally
skips the old 180-strategy dual-seed grid because that grid is not an input to
the current stage2 best-baseline reproduction; the stage1 rank-ensemble strategy
is fixed separately by the documented baseline.

## Archived Stage Packages

- `stage1/`: TRA-only rank-ensemble best baseline package.
- `stage2/`: current best stage2 package on top of stage1.

Those stage directories include archived best-baseline artifacts for inspection
and fast reproduction. They are not the entry point for a strict from-zero
retrain; use `retrain_best_baseline_from_zero.sh` for that.
